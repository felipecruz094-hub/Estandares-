LECCIONES APRENDIDAS - VITRO COLOMBIA
=======================================

1. Descomprime la carpeta.
2. Abre la carpeta "Lecciones_Aprendidas_Web_Vitro" en Visual Studio Code.
3. Abre index.html.
4. Recomendado: instala la extensión "Live Server" y usa clic derecho > Open with Live Server.

CARACTERÍSTICAS:
- Dashboard
- Registro de lecciones
- Código automático LA-AAAA-###
- Clasificación 4M
- Consulta y filtros
- Indicadores
- Detalle de cada lección
- Persistencia local en el navegador (localStorage)

NOTA:
Esta primera versión funciona sin servidor ni base de datos. Los registros se guardan en el navegador del equipo donde se utiliza.
Para una versión empresarial multiusuario se puede conectar posteriormente a MySQL/SQL Server, SharePoint, Power BI o una API.
